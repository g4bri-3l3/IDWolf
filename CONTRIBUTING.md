# Contributing to IDWolf

Thanks for your interest in IDWolf.

## Bug reports and ideas are welcome

Please open a [GitHub issue](https://github.com/g4bri-3l3/IDWolf/issues) for:

- a bug or a crash (include the PowerShell version, 5.1 or 7, and the exact
  error; never paste real directory data, snapshots or reports);
- a false positive or a check that misses something;
- an idea for a new check or an improvement.

For a **security vulnerability**, do not open a public issue: see
[`SECURITY.md`](SECURITY.md) for how to report it privately.

## Code contributions

At the moment IDWolf is maintained by a single author and **pull requests are
not being accepted**. This keeps the promise that every shipped line has been
read and that the [safety review](Test-IDWolfSafety.ps1) holds. If you would
like to contribute code, open an issue first to discuss it; this policy may
change as the project grows.
